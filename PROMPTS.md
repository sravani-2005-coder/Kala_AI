# Prompt Variation 1

## Prompt

You are an expert e-commerce copywriter.

Generate a product description for the following product.

Product Name: {name}

Category: {category}

Material: {material}

Features: {features}

### Example Input

- Product Name: Pochampally Silk Saree
- Category: Saree
- Material: Pure Silk
- Features: Handwoven, Natural Dyes

### Example Output

- Product Description
- Short marketing description explaining the product.

### Observation

The generated content was useful but quite short and lacked social media and SEO content.

# Prompt Variation 2

## Prompt

You are an expert e-commerce copywriter specializing in Indian handloom and artisan products.

Generate:

1. Product Description
2. Five Key Highlights
3. Instagram Caption
4. Five SEO Keywords

Product Name: {name}

Category: {category}

Material: {material}

Features: {features}

Keep the tone elegant, informative, and customer-friendly.

### Example Input

- Product Name: Pochampally Silk Saree
- Category: Saree
- Material: Pure Silk
- Features: Handwoven, Natural Dyes

### Example Output

- Detailed Product Description
- Five Product Highlights
- Instagram Caption
- SEO Keywords

### Observation

The response was much richer and suitable for an e-commerce website. It also included marketing content that could be directly used on social media.

# Prompt Variation 3

## Prompt

You are an experienced digital marketing specialist and luxury brand copywriter for Indian handmade products.

Generate:

- Premium Product Description
- Five Bullet Highlights
- Instagram Caption with hashtags
- SEO Keywords
- Call-to-Action

Use an emotional, luxury, and storytelling writing style.

### Example Input

- Product Name: Pochampally Silk Saree
- Category: Saree
- Material: Pure Silk
- Features: Handwoven, Natural Dyes

### Example Output

- Story-based premium description
- Luxury-focused highlights
- Instagram-ready caption with hashtags
- SEO keywords
- Marketing Call-to-Action

### Observation

The generated content was highly engaging and premium in tone. However, the response was sometimes longer than required and included extra information that needed minor editing.

---

# Best Prompt

Prompt Variation 2 produced the best overall results for the Kala AI project.

It generated well-structured content containing all the required sections, including a product description, highlights, Instagram caption, and SEO keywords. The response length was balanced, easy to read, and suitable for direct integration into the application. It also maintained a professional and customer-friendly tone, making it ideal for artisan and handloom product listings.
